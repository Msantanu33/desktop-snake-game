# Snake Game

A lightweight browser-based snake game built with plain HTML, CSS, and JavaScript.

## Demo

Open the project in your browser and start playing instantly.

## Features

- Classic snake gameplay with keyboard controls
- Score tracking and local high score saving
- Countdown-style timer display
- Start screen and game-over modal
- Responsive board layout styled with custom CSS variables

## Controls

- Arrow Up: move up
- Arrow Down: move down
- Arrow Left: move left
- Arrow Right: move right

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Launch `index.html` in a browser.

You can also serve it locally with a simple static server if preferred:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Project Structure

```text
snake-game-js/
├── index.html
├── style.css
├── script.js
├── README.md
```

## Files Overview

- `index.html` — main markup and UI structure
- `style.css` — styling, layout, colors, and game board design
- `script.js` — game logic, movement, scoring, timers, and restart behavior

## Notes

This project is intentionally simple and uses no external libraries or frameworks. It is a great beginner-friendly example of a DOM-based game built with vanilla JavaScript.
